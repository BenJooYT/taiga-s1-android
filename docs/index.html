    Reproduce it on Termux/Android

    1. Install Termux (F-Droid) + pkg install proot-distro, then proot-distro install debian.
    2. Inside Debian: apt-get install -y freecad python3 python3-venv x11-apps; python3 -m venv /root/venv-taiga; /root/venv-taiga/bin/pip install torch numpy safetensors huggingface_hub pytest.
    3. Clone shhivv/taiga-s1 to /root/taiga-s1 and pip install -e '.[dev]'. Workers use system python: FREECAD_PYTHON=/usr/bin/python3 FREECAD_LIB=/usr/lib/freecad-python3/lib plus the FreeCAD Mod dirs on PYTHONPATH (see scripts/run.sh).
    4. GUI: pkg install x11-repo termux-x11-nightly, install the Termux:X11 APK, termux-x11 :0, launch FreeCAD with the socket-server macro, drive it with scripts/gui_demo.py --goals my_goals.json --name my_part.
    5. Full scripts + goal files: scripts/ in this repo.
